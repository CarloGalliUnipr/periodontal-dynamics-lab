What to notice

Cleaning frequency changes the peak reached before each reset. The model simplifies complex biofilm growth into one saturating forcing curve.

u(τ) = umax [1 − e−kτ] · τ = time since cleaning

How to read this experiment

Blue-green rises: plaque-related forcing regrows toward a plateau. Vertical drops: cleaning instantly removes the modeled supragingival plaque, not host inflammation or the subgingival community. Shorter intervals lower the peak reached before the next cleaning.

Important limitation: this is a deliberately simple saturating forcing function, not a calibrated law of bacterial growth or a simulation of how individual bacterial species multiply.

What to notice

Increasing memory A lowers θ while keeping the constitutional threshold θ₀ fixed. The Hill exponent changes steepness, not memory.

F(S; θ) = Sn / [Sn + θn] · θ = θ₀e−A

Why the same plaque can yield a different response

The Hill function links the current signal to the inflammatory response the system is driven toward. Its threshold is θ = θ₀e−A. Moving A shifts the curve without changing the signal or constitutive threshold θ₀. Moving n changes how abruptly it rises, not how much memory persists.

This panel displays the instantaneous input–output function F, not the full inflammatory trajectory H(t). No particular Hill curve has been calibrated directly against human periodontal measurements.

What to notice

Memory can delay conversion at first but accumulate over repeated visits. The orange instant host has the same equilibrium response law, but no adaptive lag. These are simulated trajectories, not predictions for a patient.

dH/dt = −H + F(M+u; θ₀e−A)
dM/dt = r[−M+G(H)]
dA/dt = ε[αH−A]

Why conversion can be delayed despite unchanged plaque

Initially, memory is small. Plaque rises and falls more quickly than the slow adaptive state changes, which can buffer the site against conversion. Across cycles, however, memory may accumulate. A falls or rises more slowly than plaque is removed, changing the threshold of the following cycle. Conversion can occur many cycles later without any increase in the plaque peak.

Experiment 14C distinguishes three events: persistent entrapment (H stays above 0.5 throughout each cycle from the reported cycle onward), the first inflamed recall (H above 0.5 just before cleaning), and the first higher-activity recall (H above 0.8). The last is a model cutoff, not a validated threshold for clinical tissue destruction.

Adjust treatment and rechallenge

What to notice

Debridement clears the microbial state M, while H and A follow their own dynamics. Compare a genuine treatment trajectory with the earlier matched-state memory control.

With model-defined treatment, the treated site begins diseased: debridement resets M but not H or A. The optional matched-state comparator starts with equal healthy H and M and different A.

Follow the treatment sequence

1. Before treatment: the treated site occupies the active equilibrium; the naive comparison occupies the healthy equilibrium at the same baseline forcing. 2. Debridement: only microbial activity M is reset to zero. 3. Plaque control: u is held at zero for four model time units by default. 4. Rechallenge: after an adjustable recovery time, both sites receive the same step of plaque-related forcing. 5. Follow-up: the final high/low outcome is classified after a separate settling interval.

Switching to the earlier “matched reset” protocol puts H and M immediately at their healthy reference values while leaving A elevated. That comparison isolates memory particularly clearly, but it does not represent the treatment procedure itself. This graph is not a patient-specific prediction.

What to notice

When treated tissues retain acquired response memory, the same plaque input may produce greater inflammatory activity. Longer recovery can narrow that difference. Residual D represents a separate, nonrecovering structural contribution.

Challenge length = 21 days; u(t) = U[1 − e−0.5t]/[1 − e−0.5Tchallenge] · D is held fixed and adds γD to the microbial-state target

What this test can—and cannot—demonstrate

First: the treated sites are constructed from previously active states; M is reset at debridement and plaque is suppressed for four model units. Next: they recover for the selected number of illustrative days. Finally: all sites receive a 21-day regrowth challenge, and we compare their maximum model inflammation H.

The structural-D curve is a distinct clinical hypothesis: a residual defect can change the microbial conditions even if host adaptation partly recovers. The numerical relationship between D, time and inflammation is not clinically calibrated. The site should not be used to select a recall interval or interpret a patient's bleeding/plaque ratio.

ABOUT THIS PROTOTYPE

Interpret with care.

This is an experimental teaching website derived from the equations and selected dimensionless reference settings in the draft manuscript Host-response memory under periodic plaque removal. It is not a clinically validated risk calculator, and its time axis is not calibrated to actual days or recall recommendations.

The host and microbial response functions are phenomenological. The model intentionally simplifies ecological, immunological, and tissue processes. If a parameter setting produces an unfamiliar outcome, it should be read as exploratory behavior of the mathematical system—not evidence that a clinical site would behave that way.

The final article's reproducible notebooks and data should remain the primary scientific record. This page can be replaced without changing that record.
