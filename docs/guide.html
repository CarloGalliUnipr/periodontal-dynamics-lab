UNDERSTANDING THE SIMULATION

From plaque removal to response memory

This companion explains a theoretical single-site periodontal model in approachable terms. Its outputs are dimensionless and are not measured patient outcomes.

1. What are we trying to understand?

A periodontal site can become clinically quiet after microbial debridement, while tissues may retain a history of previous inflammatory exposure. The hypothesis explored here is that a slowly recovering response threshold can change how a site reacts to a later, standardized plaque challenge. This is different from a fixed susceptibility trait and different from merely remaining in the diseased basin of a bistable system.

2. What are the variables?

u: plaque-related external forcing. M: functional activity of the subgingival community. S=M+u: total modeled stimulus acting on the host. H: normalized inflammatory activity. A: slowly varying host-response memory. θ₀: fixed constitutive sensitivity threshold. θ=θ₀e−A: the current threshold after acquired adaptation. D: persistent structural loss included as a fixed contributor in the 21-day rechallenge demonstration.

What these are not: H is not a bleeding-on-probing percentage, M is not a bacterial species count, and D is not a clinical attachment-loss measurement in millimeters. They are coarse-grained, dimensionless model variables.

3. Why are there Hill functions?

A Hill function rises from nearly zero to nearly one as a stimulus increases. A parameter controls where its halfway point lies; an exponent controls how steeply it rises. Here F describes the host response to the microbial signal, and G represents the inflammatory support of the microbial state. These functions are mathematical closures used to examine reciprocal positive feedback—not empirically fitted laws of periodontal tissue biology.

F(S; θ) = Sn / [Sn + θn]
G(H) = Hq / [Hq + Kq]

4. Where does memory enter?

The host response threshold depends on A. If α is positive, sustained inflammation tends to increase A and lower θ. If inflammation resolves, A relaxes gradually. The speed of acquisition and recovery is controlled by ε: smaller ε gives a longer timescale. Thus microbial activity can fall rapidly while a heightened response tendency persists.

dH/dt = −H + F(M+u; θ₀e−A)
dM/dt = r[−M+G(H)+γD] (where the fixed D extension is used)
dA/dt = ε(αH−A)

In the reference plaque-cycle and treatment modules, D=0 and the simpler microbial equation is dM/dt=r[−M+G(H)]. The instantaneous-control host uses A=αH at every moment. This matches the memory host's equilibria but removes adaptive delay.

5. What does each online experiment test?

Plaque cycles: how repeated saturating regrowth generates cyclic external forcing. Host sensitivity: how an acquired change in threshold alters the same input–output curve. Memory ratchet (14C): how slow adaptation accumulates across cleanings, and why different progression criteria give different event times. After therapy (14B): why debridement resetting M is different from magically resetting the whole host response. 21-day gingivitis rechallenge (14A): how host history, time since debridement, and fixed structural D alter a standardized challenge.

Experiment 14 also contains robustness and episodic-disease analyses. They remain in the numerical research archive, rather than being presented as independently validated interactive modules here.

6. What does “clinical” time mean here?

The original dynamics are dimensionless. For illustration only, the work uses approximately 1.67 days per model unit; the 21-day challenge is represented as 12.6 model units. The plateau-regrowth rate used in that challenge (k=0.5) is intentionally different from the plaque-cycle example (k=0.05). These conversions and parameters have not been fitted to periodontal patient time series.

7. What is a meaningful biological test?

The strongest empirical distinction is a controlled rechallenge after different recovery intervals. If previously treated sites produce different responses under closely matched current plaque, inflammatory state and structural conditions, and the difference fades with time, that favors a recovering component over a purely constitutive difference. However, inflammatory persistence, microbial ecological memory and residual defects can also influence the response. The model alone cannot establish which mechanism dominates in patients.

8. Numerical implementation and boundaries

The website runs in-browser JavaScript using RK4 integration with short timesteps. The Experiment 14 reference settings and output files were used for qualitative and selected numerical checks; the original Python notebooks and exported data remain the authoritative source for manuscript claims. The browser models plaque removal/debridement as idealized resets, works with a single site, and does not calculate an individual patient's disease risk, prognosis or appropriate recall schedule.
