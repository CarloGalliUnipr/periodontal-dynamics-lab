MODEL GUIDE

What the simulations represent

The interactive experiments illustrate a theoretical single-site system. They are not fitted periodontal response curves or a clinical risk calculator.

Five ideas

H is normalized host inflammatory activity. M is disease-associated functional activity of the subgingival community. u is externally imposed plaque forcing; together S=M+u is the signal reaching the host. A represents slowly changing host-response memory, which modifies the effective threshold θ=θ₀e−A. A separate structural variable D is used in the manuscript's attachment-loss analyses but is not simulated here.

The coupled equations

dH/dt = −H + F(M+u; θ₀e−A)
dM/dt = r[−M+G(H)]
dA/dt = ε[αH−A]

F(S; θ) = Sn / (Sn + θn)
G(H) = Hq / (Hq + Kq)

Constitutive susceptibility is expressed by the baseline threshold θ₀. Acquired memory is expressed by A. These two effects may coexist. The adaptation parameter ε controls how quickly A changes; the instant-control host sets A=αH at all times.

What this version deliberately leaves out

The present prototype does not implement attachment-loss dynamics, tolerance (negative α), dose-dependent adaptation, stochastic plaque, or all numerical consistency checks used in the research notebooks. These can be added after the final model is frozen.

Reproducibility

The equations run in browser JavaScript with a fixed-step fourth-order Runge–Kutta integrator. This is an educational implementation, not the authoritative numerical archive. For scientific reproduction, use the final published experiment notebooks and source data.
